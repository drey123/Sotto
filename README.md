# Sotto

Sotto is an experimental browser-native anonymous confession/discovery experience.

The project is currently focused on proving the visual and interaction core before building production infrastructure.

## Current build target

**One polished 3D content object + minimal spatial test scene + continuous reading transition.**

The environment is intentionally undecided. We are researching and combining open-source 3D/rendering primitives rather than committing to a black void or a conventional game world.

- `cortiz2894/stylized-components` — reusable procedural 3D/rendering primitives
- Additional GitHub projects are being inspected for complementary rendering, simulation, interaction and spatial techniques.

## Performance principle

Sotto must remain fast while using 3D. Performance is a design constraint from the first prototype, not a later optimization phase.
